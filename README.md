# agent-sql-firewall

A blazing-fast, local AST-based SQL firewall middleware for Node.js and Express. 

Designed specifically to catch and block destructive, rogue, or hallucinated database queries generated by AI agents (e.g., unbounded `DELETE`s, CTE-wrapped `DROP TABLE`s, `DO` blocks) before they execute on your Postgres database.

## The Problem
Proxying your database traffic through a third-party AI gateway introduces unnecessary security risks and compliance friction. 

**agent-sql-firewall** Because it runs locally, no third party ever sees your queries or data, drastically reducing vendor security review cycles and compliance paperwork.

## Features
- **AST Parsing, Not Regex:** Blocks risky SQL by checking its parsed syntax tree, not regex. It understands the actual structure of the query.
- **Zero Egress:** Runs entirely inside your own VPC. 
- **Ultra-Low Latency:** Adds under 1ms of latency on short queries. 

## Installation

npm install agent-sql-firewall


## Quick Start

```typescript
import express from 'express';
import { sqlFirewall } from 'agent-sql-firewall';

const app = express();
app.use(express.json());

// Apply the firewall middleware
app.use('/api/agent-query', sqlFirewall({
  rejectDrops: true,
  rejectTruncates: true,
  requireWhereOnDelete: true
}));

app.post('/api/agent-query', async (req, res) => {
  const { query } = req.body;
  
  // If the query reaches here, it has safely passed the AST firewall.
  // Execute your pg query here:
  // const result = await pgClient.query(query);
  
  res.json({ status: 'success', query });
});

app.listen(3000, () => console.log('Firewall running on port 3000'));
